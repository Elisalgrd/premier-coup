# Premier coup

PWA d'entraînement aux échecs en français. Refonte en six phases selon `BRIEF_CODEX.md` et `CURRICULUM.md`.

Node 24 :

```sh
npm run validate
npm test
npm run build
npm start
```

Aperçu : http://localhost:4180. Le dossier `dist/` est le livrable GitHub Pages. Les données personnelles restent dans le navigateur.

Voir `ARCHITECTURE.md` pour la migration et `CHANGELOG.md` pour l'avancement. Les captures de chaque phase sont dans `docs/screenshots/`.
